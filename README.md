# Cú Đá Tiếng Hàn Của Duy (두이의 한국어 발차기)

베트남인을 위한 한국어 학습 웹앱 (Ứng dụng học tiếng Hàn cho người Việt).

- **단어 (Từ vựng)** — 명사·동사·형용사·부사 약 1,750개
- **구 (Cụm từ)** — 실전 표현 약 265개
- **문장 (Câu)** — 상황별 문장 약 230개
- **문법 (Ngữ pháp)** — TOPIK 1~3급 문법 89개, 베트남어 해설 + 예문
- **듣기 (Luyện nghe)** — 브라우저 음성합성(ko-KR)으로 단어·구·문장 듣기 연습
- 모바일 우선 UI, 라이트/다크 테마, 학습 진도 로컬 저장

## 실행 방법
`index.html` 파일 하나로 동작합니다. 브라우저로 열기만 하면 됩니다.

## GitHub Pages
저장소 Settings → Pages → Source를 `main` 브랜치 `/ (root)`로 지정하면
`https://<사용자명>.github.io/<저장소명>/` 주소로 공개됩니다.
